# ✦ LUMEN 

Un jeu pour quand je m'ennuie en cours. 

 **Jouer : https://eyub-celebioglu.github.io/lumen/**

Fais pivoter les tuiles pour relier chaque cristal à la source.
**60 niveaux** sur 5 paliers, du facile au *very high brain*. Une fois un niveau résolu, le suivant s'enchaîne automatiquement.

## Paliers

| Palier | Difficulté | Particularité |
|---|---|---|
| Éveil | Facile | Petites grilles, pour apprendre |
| Flux | Moyen | Réseaux plus grands |
| Prisme | Difficile | Jusqu'à 9×11, logique pure |
| Nébuleuse | Expert | Les bords se rejoignent (∞) |
| Singularité | Very high brain | Bords liés + lumière invisible jusqu'à la victoire |

Les niveaux s'ouvrent l'un après l'autre (ou tous d'un coup via le *mode libre* dans les réglages).

## Contrôles

- **Toucher / clic** : tourner une tuile
- **Appui long / clic droit** : verrouiller une tuile
- **Maj + clic** : tourner dans l'autre sens
- `Espace` : passer tout de suite au niveau suivant
- Clavier : `Z` annuler · `H` indice · `L` mode verrou · `R` recommencer · `Échap` retour
